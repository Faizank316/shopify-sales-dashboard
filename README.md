# Shopify Sales Dashboard

## Overview
Interactive sales dashboard created using Shopify sales data to analyze revenue trends, product performance, and regional business insights.

## Tools Used
- Power BI
- SQL
- Excel

## Features
- KPI Tracking
- Revenue Analysis
- Product Performance Dashboard
- Monthly Sales Trends
- Regional Sales Insights
- Interactive Filters & Visualizations
